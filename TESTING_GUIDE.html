🧪 Testing Guide: Fitur Edit Produk & Kategori

📋 Pre-Requisites

  • ✅ Database sudah setup dengan tabel products
  • ✅ Server running (Laragon/PHP)
  • ✅ Browser updated (untuk mendukung Fetch API)
  • ✅ JavaScript enabled

1️⃣ TEST: Tambah Produk Baru

Scenario 1.1 - Tambah produk dengan data valid

Steps:

  1. Buka halaman kasir
  2. Klik tombol "Tambah Produk" (warna hijau)
  3. Modal form akan muncul
  4. Isi form dengan data:
    • Nama Produk: Kopi Arabika
    • Kategori: Minuman
    • Harga Jual: 18000
    • Harga Modal: 6000
    • Stock: 30
  5. Klik tombol "Simpan"

Expected Result:

✓ Modal menutup, halaman reload, produk baru muncul di kategori Minuman

Scenario 1.2 - Validasi field yang wajib

Steps:

  1. Klik "Tambah Produk"
  2. Kosongi field "Nama Produk" saja
  3. Klik "Simpan"

Expected Result:

✓ Alert muncul: "Harap isi semua field yang diperlukan (*)"

API Testing

Endpoint:

POST /kasir/addProduct

Request Body:

{
  "product_name": "Teh Tarik",
  "kategori": "Minuman",
  "price": 12000,
  "cost_of_goods": 3000,
  "stock_quantity": 50
}

Expected Response:

{"status": true, "message": "Produk berhasil ditambahkan"}

2️⃣ TEST: Edit Produk Existing

Scenario 2.1 - Edit data produk

Steps:

  1. Hover di atas salah satu product card
  2. Klik ikon edit (pensil) di sudut kanan bawah
  3. Modal form akan muncul dengan data produk yang sudah terisi
  4. Ubah field "Harga Jual" dari 15000 menjadi 16000
  5. Klik tombol "Simpan"

Expected Result:

✓ Modal menutup, halaman reload, harga produk berubah menjadi Rp 16.000

Scenario 2.2 - Kategori otomatis terdeteksi

Steps:

  1. Hover product di kategori "Jajanan & Makanan"
  2. Klik edit

Expected Result:

✓ Dropdown kategori sudah menunjukkan "Jajanan & Makanan"

API Testing

Endpoint:

POST /kasir/editProduct

Request Body:

{
  "product_id": 5,
  "product_name": "Kopi Arabika Premium",
  "kategori": "Minuman",
  "price": 20000,
  "cost_of_goods": 7000,
  "stock_quantity": 25
}

Expected Response:

{"status": true, "message": "Produk berhasil diubah"}

3️⃣ TEST: Hapus Produk

Scenario 3.1 - Hapus produk dengan konfirmasi

Steps:

  1. Hover di atas product card yang ingin dihapus
  2. Klik ikon delete (sampah) di sudut kanan bawah
  3. Dialog konfirmasi akan muncul
  4. Klik "OK" untuk confirm delete

Expected Result:

✓ Alert berhasil, halaman reload, produk hilang dari grid

Scenario 3.2 - Cancel delete

Steps:

  1. Klik delete button
  2. Klik "Cancel" di dialog

Expected Result:

✓ Dialog tutup, produk tetap ada

API Testing

Endpoint:

POST /kasir/deleteProduct

Request Body:

{"product_id": 5}

Expected Response:

{"status": true, "message": "Produk berhasil dihapus"}

4️⃣ TEST: Kelola Kategori

Scenario 4.1 - Buka modal kategori

Steps:

  1. Klik tombol "Kelola Kategori" (warna biru)
  2. Modal dengan daftar kategori akan muncul

Expected Result:

✓ Modal menampilkan 3 kategori default:

  • Jajanan & Makanan
  • Minuman
  • Lainnya

Scenario 4.2 - Tambah kategori baru

Steps:

  1. Buka modal kategori
  2. Di bagian bawah form, isi input dengan Snack
  3. Klik tombol "Tambah"

Expected Result:

✓ Kategori baru "Snack" muncul di list

  • Tombol "Hapus" enabled
  • Kategori bisa dipilih di form tambah/edit produk

Scenario 4.3 - Kategori default tidak bisa dihapus

Steps:

  1. Buka modal kategori
  2. Hover di kategori "Minuman"
  3. Coba klik tombol "Hapus"

Expected Result:

✓ Tombol "Hapus" disabled (abu-abu) dan tidak bisa diklik

5️⃣ TEST: User Experience

Scenario 5.1 - Action buttons hanya muncul saat hover

Expected Result:

✓ Edit/Delete buttons hidden saat normal, muncul saat hover

Scenario 5.2 - Responsive design pada mobile

Steps:

  1. Resize browser ke ukuran mobile (max-width: 768px)
  2. Klik "Tambah Produk"
  3. Observe modal dan buttons

Expected Result:

✓ Modal dan buttons responsive, readable pada layar kecil

Scenario 5.3 - Form validation messages

Expected Result:

✓ Clear error messages untuk setiap kasus gagal

6️⃣ TEST: Database Persistence

Scenario 6.1 - Verify data di database

SQL Query:

SELECT * FROM products WHERE kategori = 'Minuman' ORDER BY product_name;

Expected Result:

✓ Produk yang ditambahkan muncul di hasil query

Scenario 6.2 - Refresh page, data tetap ada

Steps:

  1. Tambah produk baru "Smoothie"
  2. Refresh halaman (F5)

Expected Result:

✓ Produk "Smoothie" masih ada di grid setelah refresh

❌ ERROR HANDLING TESTS

Test: Hubungan dengan Server Putus

Steps:

  1. Stop server Apache/PHP
  2. Coba tambah produk

Expected Result:

✓ Alert: "Terjadi kesalahan saat menyimpan produk"

Test: Database Connection Error

Steps:

  1. Stop MySQL Server
  2. Coba edit produk

Expected Result:

✓ Alert dengan pesan error dari server

✅ Checklist Sebelum Production
